## 这是什么

不是一个"热点榜单"，而是一次**基于多源一手数据的年度盘点**：先量化注意力迁移，再逐板块给证据、代表论文与"需要保留的怀疑"。

**顶部有 Quick Start（3 分钟）**：三句话结论 + 三个核心判断 + 只记五件事 + 一页纸数字。下面每节都带一句话摘要，可跳读。

## 主要结论（TL;DR）

1. 研究重心从"造更强的模型"转向 **"把模型组织成可靠、可演化的系统"**——agent harness、记忆、环境、验证器比模型参数更重要。
2. 增长最快的技术线是 **RL 后训练 + on-policy distillation**；而 **RLHF 正在被 RLVR（可验证奖励）取代**（arXiv 同比 RLHF -40%，verifiable reward +205%）。
3. 最大的共同瓶颈是 **验证**：agent RL、RSI、自动科研、乃至学术评审本身，都卡在"我们凭什么相信这个结果是好的"。
4. **RSI 是真闭环但没有复利加速**；**长文本换了形态**（从更长窗口转向 memory / compaction / 多轮可靠性）；**生成媒体最热也最需要怀疑**（几乎没有同行评审，而它自己的评测在打假）。

## 方法

- 会议同比用**同一会议、跨年、同一口径**的关键词/标题统计（ICLR、NeurIPS 用作者关键词；ICML、CVPR 用官方标题），只做来源内趋势比较。
- arXiv 主题计数做 **CS 论文总量份额归一化**（基准 cs.LG/CL/AI/CV 一年 +27%）。
- 社区注意力用 HF upvote，但明确它**衡量注意力而非质量**（安全/非 LLM/人本 AI 在此被系统性低估）。
